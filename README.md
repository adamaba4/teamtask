# TeamTask

**TeamTask** est une application web de gestion de tâches collaborative.  
Elle permet à plusieurs utilisateurs de gérer et organiser leurs tâches au sein d’un même espace partagé, facilitant ainsi la planification du travail en groupe.

## 🎯 Objectif

L’objectif de TeamTask est de faciliter le travail collaboratif en offrant :

- Un **calendrier commun** pour visualiser les échéances du groupe  
- La **gestion des tâches** : ajout, modification, suppression  
- Un **système de communication** entre les membres  
- La possibilité de consulter ses **tâches personnelles**  
- Des fonctionnalités de **filtrage et classement** des tâches  
- Un **compteur de tâches** pour suivre la progression  

## 💻 Fonctionnalités principales

1. **Connexion et espace partagé**  
   - Chaque membre peut se connecter et accéder à un espace commun.  
   - Possibilité de créer, modifier et supprimer des tâches.

2. **Gestion des tâches**  
   - Définir des **deadlines** pour chaque tâche.  
   - Consulter et organiser ses tâches personnelles.  
   - Filtrer et trier les tâches selon différents critères.

3. **Suivi et statistiques**  
   - Compteur de tâches pour visualiser la charge de travail.  
   - Vue globale du calendrier pour planifier le travail du groupe.



Instructions pour lancer l’application :
- Créer les tables dans une base de données : php backend/config/tables,php
- Lancer dans le terminal :  php -S localhost:8050 (ou autre port)
- Lancer dans la page dans le navigateur : http://localhost:8050/accueil.html
